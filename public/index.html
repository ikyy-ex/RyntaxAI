Cara Mengaktifkan Gemini API:
  1. Buka https://aistudio.google.com/apikey dan buat API Key gratis.
  2. Salin file .env.example menjadi .env di folder proyek.
  3. Isi baris GEMINI_API_KEY=AIzaSy... dengan API Key Anda.
  4. Restart server Node.js lalu klik tombol uji koneksi di bawah.
